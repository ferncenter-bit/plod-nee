# ปลดหนี้

แอปต้นแบบสำหรับจัดการหนี้ รายจ่าย และแผนการเงินของครอบครัว

## ใช้งานในเครื่อง

เปิด `index.html` ในเบราว์เซอร์ หรือรันเซิร์ฟเวอร์ภายในโฟลเดอร์โปรเจกต์:

```bash
python3 -m http.server 8766
```

จากนั้นเปิด `http://localhost:8766/index.html`

## บัญชีทดลอง

- คุณวรัญญา / `1234`
- คุณแม่ / `1234`
- คุณน้อง / `1234`

## สถานะปัจจุบัน

- Dashboard ภาพรวมการเงิน
- เพิ่มและดูข้อมูลหนี้
- เพิ่มและดูรายจ่าย
- แผน Snowball และ Avalanche
- สมาชิกในบ้านหลายคนในโหมดทดลอง
- ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์

ระบบ Login และฐานข้อมูลข้ามอุปกรณ์ยังเป็นขั้นตอนถัดไป ไม่ควรใส่ข้อมูลจริงหรือเลขบัญชีในเวอร์ชันนี้
